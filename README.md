<h1>Sound Sketch 🎶</h1>
<h2>What is Sound Sketch</h2>
<i> Soundsketch is  app that takes audio file and give guitar or piano or another instruments tab </i>
<h2>what is this</h2>
this is a prototype of Soundsketch app that takes mp3 or wav file and give musicsheet 
<h2>this is for whom</h2>h2
this for people who want to get a musicsheet from a audio 
<h2>things used to create it</h2>
python<br>
librosa<br>
music21<br>
streamlit<br>

there was a huge problem i faced in mapping notes from frequencies i saw that a note gets generated multiple times<br>
to resolve this issue i tried different approaches and i needed find something that allows me to track at my current <br>
understanding of the libraries but the most suitable option i found was to set a limit of note duration like  <br>
if same frequencies tracked skip a note but the problem was frequencies change over time and that would mean its for<br>
exact same frequencies to tracked so i came up with a solution yeah there are complex method but the most simple  method was <br>
to track it over time like the  get a about value like if from x frequency to y frequency is tracked continuously for a certain <br>
duration of time and if it fell under that duration its  simplest method but not best 

<h2> limitations </h2>
it's still prototype and under development it don't track duration so notes may not be  accurate <br>
it's currently optimized for simple piano or guitar recording <br>
the generated music sheet may contain incorrect notes
